Privacy Policy – Zunda Marble Cup Uploader

Last updated: November 15, 2026

What this app is

Zunda Marble Cup Uploader is a private tool used only by the owner of the YouTube channel “Zunda Marble Cup” to upload and schedule the channel's own videos and to read the channel's own video statistics. It is not offered to the public.

Data the app accesses

  • YouTube Data API scope youtube.upload: to upload videos created by the channel owner and set their title, description and publish time.
  • YouTube Data API scope youtube.readonly: to read the channel name and the view, like and comment counts of the channel's own videos.

How data is used and stored

  • Data is used only to upload the channel's videos and to record their performance for the owner.
  • The authorization token and statistics are stored only on the owner's own computer. Nothing is sent to any server other than Google's YouTube API.
  • No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How to revoke access

Access can be removed at any time at https://myaccount.google.com/permissions.

Contact

Please contact the channel owner through the YouTube channel Zunda Marble Cup.

プライバシーポリシー（日本語）

Zunda Marble Cup Uploader は、YouTube チャンネル「Zunda Marble Cup」の運営者だけが、自分のチャンネルの動画をアップロード・予約公開し、自分の動画の再生数などを確認するための非公開のツールです。一般には提供していません。

利用する権限は youtube.upload（動画のアップロードとタイトル・説明・公開日時の設定）と youtube.readonly（チャンネル名と自分の動画の再生数・高評価数・コメント数の取得）だけです。認可情報と統計は運営者のパソコンにだけ保存し、Google の YouTube API 以外には送りません。第三者への提供・販売・広告への利用はしません。Google API Services User Data Policy（Limited Use の要件を含む）に従います。
